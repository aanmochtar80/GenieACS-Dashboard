Koneksi WireGuard Tunnel

Jalur tunnel privat berkecepatan tinggi antara VPS dan router MikroTik untuk komunikasi API & TR-069.

Status Tunnel Active (Interface wg0)
IP VPS (Local Gateway) {{ .ServerIP }}/24
IP MikroTik (Remote Peer) {{ .MikroTikIP }}/24
Port UDP WireGuard 51820 / UDP

Konfigurasi RouterOS v7

MikroTik Script

Tempelkan perintah ini di Terminal Winbox MikroTik Anda:

/interface wireguard add name=wg-vps listen-port=51820
/ip address add address=10.10.10.2/24 interface=wg-vps
/interface wireguard peers add interface=wg-vps endpoint-port=51820 allowed-address=10.10.10.1/32 persistent-keepalive=25s
/ip service enable api
/ip service set api port=8728
